A simple, semi-functional website I created when I was bored. This project represents my initial attempt at web development, combining HTML, CSS, and JavaScript to create a basic but functional webpage.

## 📋 About

This project was made purely out of curiosity and boredom. It's not meant to be groundbreaking, but rather a learning experience and a fun way to pass the time while exploring web development basics.
